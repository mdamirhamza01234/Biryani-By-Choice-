# Biryani By Choice — Bhagalpur Website

Responsive restaurant website prepared for GitHub Pages.

## Included
- Full menu transcribed from the three menu images supplied by the restaurant/customer.
- Menu categories: Hyderabadi Biryani, Chowmein/Noodles, Chinese Starters, Main Course, Kolkata Rolls, Drinks/Mojito, Rice & Extras.
- Filterable menu, mobile navigation, food imagery, contact and map buttons.
- Correct menu address: Ground Floor, Dayal Building, K.B. Lall Road, Nathnagar, Bhagalpur.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of a GitHub repository.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.

## Important
Menu names and prices are transcribed from the supplied menu photos. Some photos show overlapping/alternate biryani price listings, so both sets are retained where visible. Please confirm the current approved prices with the restaurant before publishing. Food images are illustrative stock photos, not actual restaurant food photos. Replace them with owner-approved dish photos when available. Phone number and business hours should also be confirmed before public launch.
